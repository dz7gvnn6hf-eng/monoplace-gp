# Monoplace GP

Jeu de course de monoplaces en vue de dessus : Grand Prix, championnat, contre-la-montre, éditeur de circuit et course en ligne entre amis.

Jouer : https://dz7gvnn6hf-eng.github.io/monoplace-gp/

Tout le jeu tient dans `index.html`. Le jeu en ligne passe par des connexions directes entre joueurs (PeerJS).

Bonus : `tank.html`, un tank en vue de dessus 3/4 ou un navire de guerre, sur un terrain naturel (herbe, collines, lac) (https://dz7gvnn6hf-eng.github.io/monoplace-gp/tank.html).
